# 3.4 주석

Rust의 주석 종류는 크게 3가지야.

## 1. 라인 주석
```rust
// 이 줄은 주석이다. 컴파일에 영향 없음.
let x = 5; // 코드 뒤에 붙여도 됨
```

## 2. 블록 주석
```rust
/* 여러 줄에 걸친
   주석을 쓸 때 사용 */
```

## 3. 문서화 주석 (doc comment)
- `///` : 바로 아래 항목(함수, 구조체 등)을 문서화. `cargo doc`으로 HTML 문서 생성 가능.
- `//!` : 그 주석이 포함된 모듈/파일 전체를 문서화 (보통 파일 맨 위에 씀).

```rust
/// 두 수를 더한다.
///
/// # Examples
/// ```
/// let result = add(1, 2);
/// assert_eq!(result, 3);
/// ```
fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

## 확인 문제 (개념만 체크)
아래 중 컴파일 에러가 나는 것은?

```rust
// A
let x = 5; // 주석

// B
/* let y = 10; */

// C
/// let z = 15;
```

**정답**: 셋 다 컴파일 에러 없음. C는 doc comment라서 `fn`/`struct` 등 "문서화 대상" 바로 위에 있어야 의미가 있지만, 그냥 단독으로 있어도 컴파일 에러는 아님 (경고 정도만 날 수 있음).

체크했으면 `3.5 함수`(이미 완료)에 이어서 `3.6 제어문`으로.
