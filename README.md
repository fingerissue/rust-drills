# Just Do Rust 복습용 레포

위키독스 "Just Do Rust - 러스트 기초부터 고급까지" (지은이: 박희진, 박지헌, https://wikidocs.net/book/16747) 를
읽으면서 챕터별로 복습 문제를 풀어보기 위한 개인 학습용 레포다.

문제는 Claude(Anthropic)가 책 목차와 본문을 참고해서 만들었다.

## 구조

책의 목차를 그대로 따라간다.

```
01. 프로그래밍 환경 구축하기/
  1.1 Rust 설치하기/
  1.2 VS Code 설치하기/
  1.3 첫 번째 프로그래밍 - Hello world/
02. 입문/
  2.1 무작정 따라하며 Rust 코드 짜 보기/
  2.2 작성한 코드 이해하기/
```

각 하위 폴더에는 보통 두 개의 파일이 있다:
- `problem.rs` — `TODO` / `todo!()` 부분을 채우면서 푸는 문제 파일
- `answer.rs` — 막혔을 때만 보는 정답 파일

환경 구축처럼 코드가 없는 챕터(1.1, 1.2)는 `체크리스트.md` 로 대체.

## 사용법

각 폴더에서:
```bash
rustc problem.rs -o problem && ./problem
```
로 실행하면서 TODO를 채워나가면 된다. (아직 Cargo 프로젝트로 안 묶어놨음 — 나중에 크레이트 의존성 필요한 챕터
가 나오면 그때 Cargo 프로젝트로 전환할 예정)
