# 6.4 GUI 프로그래밍 (egui)

## 왜 코드 문제가 없나?
egui는 실제 창을 띄우는 즉시 모드(immediate mode) GUI 라이브러리라, 디스플레이가 없는 서버/컨테이너
환경에서는 자동으로 실행/검증할 방법이 없다. 그래서 이 섹션은 개념 정리로 대체한다.

## 핵심 개념

### 1. 즉시 모드 GUI란?
매 프레임마다 UI 전체를 다시 "그리라"고 코드로 지시하는 방식. 리액트처럼 상태가 바뀌면
자동으로 다시 그려주는 게 아니라, 매 프레임 직접 `ui.button("클릭")` 같은 코드를 실행해서
그 프레임의 UI를 구성한다.

```rust
impl eframe::App for MyApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        egui::CentralPanel::default().show(ctx, |ui| {
            ui.label(format!("카운트: {}", self.count));
            if ui.button("증가").clicked() {
                self.count += 1;
            }
        });
    }
}
```

### 2. 상태(State)는 그냥 구조체 필드
egui 앱은 보통 구조체에 상태를 들고 있다가, `update()` 안에서 그 상태를 읽고 바꾸는 식으로 동작한다.
아래는 위 계산기/카운터 앱의 "로직만" 떼어내서, GUI 없이도 테스트 가능하게 만든 버전이다.
(실제 화면은 로컬 PC에서 `cargo run`으로 직접 확인해야 함)

```rust
struct CounterApp {
    count: i32,
}

impl CounterApp {
    fn on_increment(&mut self) {
        self.count += 1;
    }
    fn on_decrement(&mut self) {
        self.count -= 1;
    }
}

fn main() {
    let mut app = CounterApp { count: 0 };
    app.on_increment();
    app.on_increment();
    app.on_decrement();
    assert_eq!(app.count, 1);
    println!("카운터 로직 테스트 통과: {}", app.count);
}
```

이 패턴(버튼 클릭 -> 메서드 호출 -> 상태 변경)이 egui 앱의 핵심이다. 실제 버튼을 `ui.button(...).clicked()`로
감지해서 저 메서드를 호출하기만 하면 된다.
